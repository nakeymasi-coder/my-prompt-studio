# My Prompt Studio

A beginner-friendly All-Purpose Prompt Studio built as one self-contained HTML page.

## Open the app

Download `index.html` and open it in your browser. No installation, dependencies, or API key is required.

Choose a category, type a topic and audience, select your tone, output format, and detail level, then click **Generate Prompt**. Use **Copy Prompt** to paste the completed prompt into ChatGPT. **Clear All** resets every field.

This tool writes prompts; it does not generate the finished content or images.
